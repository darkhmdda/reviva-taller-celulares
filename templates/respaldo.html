Cómo restaurar un respaldo

  1. Detén el sistema (Ctrl+C en la terminal).
  2. Copia el archivo de respaldo a la carpeta database del proyecto con el nombre taller.db (reemplaza el actual; guarda antes una copia de ese).
  3. Vuelve a iniciar con python app.py.
